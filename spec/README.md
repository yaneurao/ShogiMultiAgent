# 開発・引き継ぎ資料

ShogiMultiAgent は、複数の USI エンジンを CSA 対局サーバーへ接続する Windows 向けデスクトップアプリです。サーバーのソースコードや別リポジトリを取得しなくても、このリポジトリをビルド・変更できます。

- [構成とデータの流れ](architecture.md)：プロセス、画面、設定、棋譜と履歴
- [USI・CSA と先読み](protocol.md)：接続から終局までの状態と注意点
- [開発・検証・ビルド](development.md)：環境、コマンド、テスト、配布前の確認
- [画面・操作の仕様](participant-app.md)：機能と UI の設計上の約束

利用者向けの操作と保存場所は、リポジトリ直下の [README](../README.md) を参照してください。資料と実装が食い違う場合は、実装とテストを確認し、必要に応じて両方を更新してください。
