# USI・CSA と先読み

## 接続から終局まで

1. アダプターはエンジンを起動し、usi / usiok、オプション設定と準備を行う。エンジンの作業フォルダは実行ファイルの親フォルダ。
2. CSA サーバーへ接続し、プレイヤー名と対局条件・trip で LOGIN する。ゲーム情報を検証して AGREE し、START を待つ。
3. 局面と残り時間を管理し、自分の手番に position / go を送る。エンジンの bestmove を CSA の着手に変換して送信する。
4. 終局時は探索を停止して応答を回収し、gameover を送る。連続参加なら次の接続へ進む。

接続後の無通信対策として CSA 空行を30秒ごとに送る。ログイン応答と対局開始通知には30秒のタイムアウトがある。現在対応する CSA 時間単位は 1sec、時間遅延は 0。秒読みと加算の併用は未対応で、未対応の条件では開始しない。通信時の持ち時間の計算と CSA 棋譜の取り扱いは adapter/src/usi_agent.rs を確認する。

## 先読み

設定の ponder は初期状態で無効。有効なら USI 初期化時に USI_Ponder=true を送る。自分の指し手がサーバーから返った後、bestmove の予想手が合法なとき、その手を含む局面で go ponder を送る。

- 予想が当たれば ponderhit を送り、その探索を通常思考として継続する。
- 外れれば stop を送り、停止した探索の bestmove を捨ててから実局面で go する。
- 予想手がない・不正な場合は先読みせずに待つ。
- 終局・切断時も探索停止と bestmove の回収を行ってからエンジンを再利用する。停止応答が10秒以内に届かなければエラーとして終了する。

読み筋を含む info は各行を analysis_update として通知し、depth、seldepth、評価値、Bound、nps、読み筋と探索局面を渡す。読み筋のない info は履歴行にしない。先読み中の info は、その予想手を適用した局面に対するもの。表示用に通常思考と区別し、読み筋の日本語変換にも予想局面を使う。予想が外れた探索の結果を、実際の指し手や棋譜コメントに混ぜない。

## Electron とアダプターの通信

アプリはアダプターを --app-mode で起動し、最初の標準入力行に設定を JSON で渡す。その後 q は終局待ちの終了予約、c は予約取消。標準出力は１行１イベントの JSON Lines で、state、game_started、move、search_state、analysis_update、analysis、game_finished などを送る。フィールドや順序を変更する場合は app/main.js の eventFor と連携テストも更新する。

終了予約は進行中の対局を切らない。強制終了は別操作であり、対局中は切断負けになる場合がある。標準入力が閉じた場合も無人のエンジンを残さないため、終局後に終了する。
