# USIエンジン参加アプリ

このリポジトリ はWindows x64向けElectronアプリ「ShogiMultiAgent」。接続設定には設定名、プレイヤー名、CSA接続先、USIエンジン、対局条件、trip、任意の棋譜フォルダとUSIオプションを保存する。接続設定は設定名を変更せずに複製でき、保存済みtripは初期状態で伏せて表示し、表示ボタンで確認できる。複製ではtripの暗号化データを引き継ぐ。設定ファイルの場所は画面に表示し、改名前との互換性のためWindowsでは `%APPDATA%\shogizone-participant\connections.json` を使用する。新しく入力するtripは初期状態で見え、編集時に欄を空にして保存すると削除する。tripはElectron safeStorageのWindows DPAPIで暗号化し、平文を設定ファイルに保存しない。CSA通信自体は平文である。Windowsの同じユーザーで動く他のアプリからの保護は保証しない。

各接続はRust製usi-agentの独立プロセスとして起動し、`--app-mode` では起動設定を標準入力のJSON、状態・局面・手番側の評価値・読み筋を標準出力のJSON Linesで受け渡す。tripはコマンドライン引数や表示ログに出さない。エンジンはその実行ファイルの親ディレクトリで起動する。プレイヤー名・接続先・状態・手数・評価値を一覧表示し、タブで盤面と進捗を切り替える。ShogiZone と floodgate の対局は盤面列のブラウザボタンから各サーバーの日別観戦ページを開ける。対応しない接続先や不正な対局 ID ではボタンを無効にする。

「終了予約」は各エージェントへqを送り終局を待つ。参加中の接続設定では参加ボタンを無効にする。終了した接続を再参加させるときは、参加状況の行と接続詳細のタブの位置を引き継ぐ。設定名を編集すると、実行中の接続の一覧・タブにも即時反映する。強制終了には確認ボタンを表示し、操作と終了コードは進捗ログに記録する。Windowsではtaskkill /Tでエンジンを含むプロセスツリーを終了する。参加中のウィンドウを閉じると終局待ちの確認を表示し、エンジンを終了してからアプリを閉じる。アプリが異常終了して標準入力が閉じた場合も、エージェントは終局後に終了する。棋譜保存はエージェントのCSA保存機能を利用する。

`scripts/build-windows.sh` はRustエージェントとElectronアプリをWindows x64向けにビルドする。独立したエージェント用Cargo定義を用い、Unix専用サーバーをWindowsでビルドしない。Electronのasar内の実行ファイルをspawnできないためasarは無効にする。配布は生成したフォルダ全体。

`tests/usi_agent_app_e2e.py` はJSON Lines、tripを含むLOGIN、CSA棋譜、終局待ちを実CSA/USIの模擬相手で検証する。`tests/participant_app_e2e.cjs` は実Electron画面から2接続、trip暗号化、局面・評価値、一方の終了中に他方が継続することを検証する。

接続先はShogiZoneとfloodgateの候補を選べ、任意のホスト名・ポートも入力できる。参加準備中から同じ設定の再参加を画面とプロセス管理の両方で防ぐ。参加時のエラーはその設定の参加ボタン付近に表示する。

アプリ名の右の歯車からアプリ設定を開ける。自分が参加中のプレイヤー同士のマッチングを強制切断する設定は初期値オフで、settings.json に保存する。オンの場合は同じ接続先の参加中プレイヤーを照合し、対局情報を確認して AGREE 前に各接続を強制終了する。実行中の外部アプリや別サーバーのプレイヤーは検出できない。

画面は「参加状況」と「接続設定」のタブに分ける。接続設定の見出しは「接続設定を追加」「すべて参加」の順に置き、操作列は「編集」「複製」「参加」の順とする。追加と編集、すべて参加と参加は、それぞれ同じ色にする。tripの削除専用チェックボックスは設けず、欄を空にして保存すると削除する。設定名変更は実行中のタブにも反映するが、進行中のプレイヤー名や接続先は変更しない。参加のエラーは該当設定のボタン付近に表示する。

表の操作列に固定幅のボタンだけを並べる場合、列はボタンに必要な幅にとどめ、余った幅を設定名やプレイヤー名など内容の長い列に配分する。ウィンドウを広げたときに操作列だけが広がり、ボタンの周囲に不要な空白が生じる設計にしない。

接続設定は↑・↓で順番を変更し、一括選択して削除できる。参加中の設定は削除できない。参加状況の「まとめて参加」は未参加の設定を起動し、終了予約中の接続には取り消しを送る。対局中の取り消しは現在の対局を継続し、終局と重なって切断された場合は再参加する。「まとめて終了予約」は終局後に終了する。

対局棋譜一覧では、現在の接続設定のプレイヤー名を先手・後手名と照合し、先手のみ・後手のみ・先後両方を勝敗と組み合わせて絞り込める。接続設定から名前がなくなった対局は該当する絞り込みに含まれない。

対局棋譜一覧は1ページの件数を100〜1000件まで100件刻みで選択でき、初期値は100件。件数変更時は最初のページへ戻り、選択済み棋譜は保持する。

対局棋譜一覧の選択棋譜は、ページをまたいで選択したままフォルダを指定して一括書き出しできる。保存済みCSAをコピーし、同名ファイルは上書きせず枝番号を付ける。元のCSAがない場合や書き出しに失敗した場合は対象ごとに理由を表示し、成功分は保持する。対局中の棋譜は書き出さない。

対局棋譜一覧の「コピー」は、その行の保存済みCSAファイルの全文をクリップボードにコピーする。ファイルがない場合は無効にし、読み取り失敗は操作位置に表示する。

接続設定の「相手の手番中に先読みする」は初期値オフで、設定の複製時も引き継ぐ。有効時はエンジン初期化で `USI_Ponder=true` を送り、実際の自分の指し手がサーバーから返った後、`bestmove` に付いた合法な予想手を加えた局面で `go ponder` を送る。予想が当たれば `ponderhit`、外れれば `stop` に対する `bestmove` を破棄してから実局面で通常思考する。予想手がない・不正な場合は先読みせず相手の着手を待つ。終局や切断時も進行中の探索を停止し `bestmove` を受け取ってからエンジンを再利用する。停止応答が10秒以内にない場合は安全のため再利用せずエラー終了する。

接続の詳細の「思考ログ」には、接続ごとの現在の思考または先読みの状態と探索情報を表示する。見出しの右に探索局面数と nps の最新値を表示する。読み筋を含む info ごとに思考時間（1時間未満は `mm:ss`、1時間以上は `h:mm:ss`）、depth / seldepth、評価値、評価値の下限記号 `--`・上限記号 `++`（確定値には記号なし）、最大4手の読み筋を固定幅の列で1行にまとめ、新しい行を先頭に追加する。各探索局面の直近100行を対局中のメモリに保持し、棋譜の再生位置を戻した場合は該当局面の探索履歴を表示する。探索履歴はファイルに保存しない。過去局面の表示は局面が変わるまで再取得・再描画せず、思考ログの内容が変わらない場合は行を作り直さない。固定高さの領域内でスクロールする。探索終了後も次の探索情報が届くまで残し、通常思考でも先読みでも表示する。先読みの予想が外れた場合は予想局面の情報を消す。読み筋は実際の探索局面を基準に日本語表記へ変換し、棋譜に記録された各局面の情報とは別に扱う。先読みが設定上有効でも、予想手が得られていない間は待機中と表示する。

盤面の下の再生操作ボタンの下に、その局面の指し手・評価値・読み筋を表示する。評価値グラフは接続詳細の右側に配置する。
