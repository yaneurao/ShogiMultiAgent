# チュートリアル 2/5：接続設定を作る

エンジンと接続先を設定として保存します。設定は後から編集でき、次回も使えます。

## 必要な項目を入力する

1. 画面上部の「接続設定」を開きます。
2. 「＋ 接続設定を追加」を押します。
3. 次の項目を入力します。

| 項目 | 入力する内容 |
| --- | --- |
| 設定名 | アプリ内で見分けるための名前。例：`エンジンA / ShogiZone` |
| プレイヤー名 | サーバーに参加するときの名前。サーバーの利用ルールに従ってください。 |
| 接続先 | ShogiZone または floodgate を選びます。他のサーバーの場合は「任意」を選び、`ホスト名:ポート` を入力します。 |
| 対局条件 | 参加先で指定されている条件。初期値が接続先の条件に合うか確認してください。 |
| エンジン本体 | 「参照」を押し、用意した将棋エンジンの `.exe` ファイルを選びます。 |

## 必要に応じて設定する

- **trip**：サーバーで必要な場合に入力します。保存時は Windows の暗号化機能で保護されますが、CSA通信自体は暗号化されません。編集時に空欄にして保存すると削除されます。
- **棋譜の保存先**：新規設定にはアプリのデフォルト保存先が入力されます。個別に変更する場合は「参照」でフォルダを選びます。空欄の場合は対局時のデフォルト保存先を使います。
- **相手の手番中に先読みする**：最初はオフのままで構いません。対応エンジンで使う場合にオンにします。
- **USIオプション**：エンジンの説明に従い、必要な場合だけ `Threads=2` のように1行に1つ入力します。

入力後、「設定を保存」を押します。「接続設定」の一覧に設定が表示されたら、次へ進みます。

デフォルト保存先は画面左上の歯車から変更できます。初期値は `ドキュメント\ShogiMultiAgent\kif` です。変更は新規の接続設定の初期値と、保存先が空欄の接続設定に反映されます。すでに保存先が入力されている接続設定は変更されません。

### 一括参加から外す

使わない接続設定は、編集画面で「この設定を無効にする」にチェックを入れて保存できます。無効な設定は一覧がグレーになり、「すべて参加」「まとめて参加」の対象から外れます。設定を残したまま、個別の「参加」ボタンで参加することもできます。
