# チュートリアル 3/5：対局に参加する

## 参加する

1. 「接続設定」の一覧で、作成した設定の「参加」を押します。
2. 「参加状況」を開き、接続したエンジンの状態を確認します。
3. 対局が始まると、エンジンが自動的に指します。対局開始までの待ち時間や対戦相手の決まり方はサーバーによって異なります。

「盤面」を押すと、その接続の盤面、進捗、思考ログなどを確認できます。思考中にエンジンが送る `info string` も思考ログに表示します。表示を切り替えるには、左上の歯車から「アプリ設定」を開き、「思考ログにエンジンの info string を表示する」を変更してください。別の接続設定を追加して参加させると、複数のエンジンを同時に動かせます。接続の詳細にあるタブで表示を切り替えてください。

自分が参加させたプレイヤー同士の対局を避けたい場合は、画面左上の歯車からアプリ設定を開き、「自分が参加させているプレイヤー同士の対局は、マッチング時に強制切断する」を有効にできます。初期状態ではオフです。強制切断は対局サーバーに切断として扱われます。

## 終了する

「参加状況」で対象の「終了予約」を押すと、対局中なら終局を待ってからログアウトします。複数の接続をまとめて終了するには「まとめて終了予約」を使います。

「強制終了」は接続をすぐに終了し、対局中は切断負けになることがあります。通常は「終了予約」を使ってください。参加中にウィンドウを閉じる場合も、終局を待つ選択ができます。

## うまく参加できないとき

- 「参加」ボタン付近のエラーを確認し、エンジンの `.exe`、必要なファイル、接続先、プレイヤー名、対局条件を見直してください。
- 必要なファイルや USI オプションは、エンジンの説明を確認してください。エンジンは `.exe` のあるフォルダを作業フォルダとして起動します。
- ログインを拒否された場合は、表示された理由とサーバーの利用条件を確認してください。
- CSA の時間単位は `1sec`、時間遅延は `0` に対応しています。秒読みと時間加算の併用など、未対応の条件では参加を停止します。
