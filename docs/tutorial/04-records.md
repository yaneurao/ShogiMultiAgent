# チュートリアル 4/5：棋譜を確認する

## アプリで再生する

1. 画面上部の「対局棋譜」を開きます。
2. 見たい対局の「盤面」を押します。
3. 盤面の下にあるボタンで、最初や最後の局面へ移動したり、1手ずつ進めたりできます。

一覧の「コピー」では保存済み CSA 棋譜の全文をコピーできます。複数の対局にチェックを入れて「選択した棋譜を書き出し」を押すと、フォルダを指定してまとめて書き出せます。

## 保存先を確認する

接続設定で保存先を指定しなかった場合、CSA 棋譜は `%USERPROFILE%\Documents\ShogiMultiAgent\kif` に保存されます。各行の「保存先」からもファイルの場所を開けます。

CSA 棋譜の保存に失敗した場合や、対局が中断して棋譜が最後まで保存されなかった場合は、その理由が表示されます。途中までしか保存できなかったファイルは通常のコピー・開く・書き出しができません。「保存先」から部分ファイルの場所を確認できます。

対局一覧と局面の履歴は別に `%APPDATA%\shogizone-participant\game-history` に保存されます。接続設定は `%APPDATA%\shogizone-participant\connections.json` に保存されます。以前の設定を引き継ぐため、フォルダ名は以前のままです。

アプリやパソコンが予期せず終了した場合は、次回起動時に保存済みの局面を復旧します。終局結果も復旧用データに保存済みなら復旧し、それ以外は「結果不明」となります。書き込み前の最新の指し手や結果は復旧できない場合があります。
