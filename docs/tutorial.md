# はじめての ShogiMultiAgent

このチュートリアルでは、Windows で将棋エンジンを1つ登録し、CSA対局サーバーに参加して棋譜を確認するまでを説明します。ShogiMultiAgent はエンジン同士の対局に参加するアプリです。利用者が盤面をクリックして指すアプリではありません。

## 1. 用意するもの

- Windows x64 のパソコンとインターネット接続
- ShogiMultiAgent の配布フォルダ一式。ZIP で受け取った場合は展開してください。ビルドする場合は [README のビルド方法](../README.md#ビルド)を参照してください。
- Windows で動作する **USI対応の将棋エンジン**。エンジンは別途入手し、必要な評価関数ファイルなども、エンジンの説明に従って配置してください。
- 参加する CSA 対局サーバーの利用方法、プレイヤー名や対局条件。必要な登録や利用ルールはサーバーごとに確認してください。

USI は将棋エンジンとアプリの間、CSA はアプリと対局サーバーの間で使う通信方式です。エンジン本体として指定するのは、エンジンの `.exe` ファイルです。

## 2. アプリを起動する

配布フォルダ内の `ShogiMultiAgent.exe` を開きます。実行ファイルだけを別の場所に移さず、同じフォルダにあるファイル一式をそのまま使ってください。

## 3. 接続設定を作る

1. 画面上部の「接続設定」を開き、「＋ 接続設定を追加」を押します。
2. 次の項目を入力します。

| 項目 | 入力する内容 |
| --- | --- |
| 設定名 | アプリ内で見分けるための名前。例：`エンジンA / ShogiZone` |
| プレイヤー名 | サーバーに参加するときの名前。サーバーの利用ルールに従ってください。 |
| 接続先 | 候補から ShogiZone または floodgate を選択します。他のサーバーの場合は「任意」を選び、`ホスト名:ポート` を入力します。 |
| 対局条件 | 参加するサーバーで指定されている条件を入力します。初期値が接続先の条件に合うか確認してください。 |
| エンジン本体 | 「参照」を押して、用意したエンジンの `.exe` ファイルを選びます。 |

3. 必要に応じて残りの項目を設定し、「設定を保存」を押します。

- **trip**：サーバーで必要な場合に入力します。保存時は Windows の暗号化機能で保護されますが、CSA通信自体は暗号化されません。編集画面で空欄にして保存すると削除されます。
- **棋譜の保存先**：空欄なら `ドキュメント\ShogiMultiAgent\kif` に保存されます。別の場所に保存したい場合は「参照」で選びます。
- **相手の手番中に先読みする**：最初はオフのままで構いません。対応エンジンで使う場合にオンにします。
- **USIオプション**：エンジンの説明に従い、必要な場合だけ `Threads=2` のように1行に1つ入力します。

## 4. 対局に参加する

「接続設定」の一覧で、作成した設定の「参加」を押します。「参加状況」に接続と状態が表示されます。対局が始まると、エンジンが自動的に指します。対局開始までの待ち時間や対戦相手の決まり方はサーバーによって異なります。

「盤面」を押すと、その接続の盤面、進捗、現在の読み筋などを確認できます。複数の設定を参加させた場合は、接続の詳細にあるタブで表示を切り替えられます。

## 5. 終了する

「参加状況」で対象の「終了予約」を押すと、対局中なら終局を待ってからログアウトします。複数の接続をまとめて終了するには「まとめて終了予約」を使います。

「強制終了」はすぐに接続を終了します。対局中は切断負けになることがあるため、通常は「終了予約」を使ってください。参加中にウィンドウを閉じる場合も、終局を待つ選択ができます。

## 6. 棋譜を見る

「対局棋譜」タブで対局の「盤面」を押すと、保存された局面を再生できます。棋譜の一覧から CSA ファイルのコピーや書き出しもできます。保存先を指定しなかった場合、CSA ファイルは `%USERPROFILE%\Documents\ShogiMultiAgent\kif` にあります。

## うまく参加できないとき

- 「参加」ボタン付近のエラーを確認し、エンジンの `.exe`、必要なファイル、接続先、プレイヤー名、対局条件を見直してください。
- エンジンの実行に必要なファイルや USI オプションは、エンジンの説明を確認してください。エンジンは `.exe` のあるフォルダを作業フォルダとして起動します。
- ログインを拒否された場合は、表示された理由とサーバーの利用条件を確認してください。
- アプリは CSA の時間単位 `1sec`、時間遅延 `0` に対応しています。秒読みと時間加算の併用など、未対応の条件では参加を停止します。

詳しい保存先やビルド方法は [README](../README.md)、開発者向けの説明は [spec/](../spec/README.md) を参照してください。
