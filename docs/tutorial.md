# チュートリアル 1/5：準備する

ShogiMultiAgent は、将棋エンジンを CSA 対局サーバーに参加させる Windows x64 向けアプリです。対局が始まるとエンジンが自動で指します。このチュートリアルでは、エンジンを1つ参加させ、棋譜を確認するまでを説明します。

## 用意するもの

1. **Windows x64 のパソコンとインターネット接続**を用意します。
2. **ShogiMultiAgent の配布フォルダ一式**を用意します。ZIP で受け取った場合は展開してください。ソースから作成する場合は [5/5：ビルドする](tutorial/05-build.md) を先に参照してください。
3. **USI対応の将棋エンジン**を別途入手します。Windows で動作するものを選び、エンジンの説明に従って評価関数などの必要なファイルも配置します。
4. 参加したい **CSA 対局サーバー**の利用方法を確認します。必要な登録、プレイヤー名、対局条件はサーバーごとに異なります。

USI はアプリと将棋エンジンの間、CSA はアプリと対局サーバーの間で使う通信方式です。設定時には、将棋エンジン本体の `.exe` ファイルを選びます。

## アプリを起動する

配布フォルダ内の `ShogiMultiAgent.exe` を開きます。実行ファイルだけを移動せず、配布フォルダ内のファイル一式をそのまま使ってください。

次に、エンジンと接続先を登録します。
