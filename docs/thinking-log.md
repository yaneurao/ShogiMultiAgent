# 思考ログの読み筋に表示される特殊な記号

やねうら王などのエンジンは、読み筋の中に指し手とは別の記号を出力することがあります。これらは、同じ局面の繰り返しや、手駒の優劣に関する探索結果を表します。

| 記号 | 意味 |
| --- | --- |
| `rep_sup` | 手駒の優等局面 |
| `rep_inf` | 手駒の劣等局面 |
| `rep_draw` | 千日手による引き分け |
| `rep_win` | 連続王手の千日手などによる勝ち |
| `rep_lose` | 連続王手の千日手などによる負け |

思考ログでは、これらの記号をエンジンから受け取ったまま表示します。たとえば `7g7f 3c3d rep_draw` という読み筋は、指し手を日本語表記にした後、末尾に `rep_draw` と表示します。

思考ログには読み筋の先頭4要素を表示します。記号も1要素として数えるため、5要素目以降にある記号は表示されません。また、CSA棋譜の読み筋コメントには、これらの記号は保存されません。
